# SAP SAC Revenue & Profit Analytics

A business intelligence dashboard project built using SAP Analytics Cloud (SAC) focused on revenue, profitability, and sales performance analysis using Global Bike transaction data.

## Project Overview

This project demonstrates the use of SAP Analytics Cloud (SAC) for KPI reporting, business performance analysis, and interactive dashboard development.

The dashboard focuses on:

* Revenue analysis
* Profitability tracking
* Product-level performance
* Regional sales insights
* KPI-driven business reporting

---

## Key Features

* Built KPI models for Revenue, Profit, Sales Quantity, and Profit Margin analysis
* Developed interactive SAC dashboards for regional and product-level analysis
* Used SAC Smart Insights and Smart Discovery to identify top-performing products and profitability drivers
* Analyzed revenue concentration patterns across business categories

---

## Technologies Used

* SAP Analytics Cloud (SAC)
* KPI Reporting
* Dashboard Development
* Business Intelligence Analytics
* Data Visualization

---

## Dashboard Insights

* Revenue and profit trends analyzed across multiple regions
* Product-level profitability analysis performed using KPI visualizations
* Smart Insights used to identify high-performing products and business drivers
* Interactive dashboards enabled business-focused performance tracking
